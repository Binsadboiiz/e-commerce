# Seller Onboarding

This feature handles the complete seller registration workflow.

## Modules

- Registration
- Address
- Bank
- Business
- Documents
- Review
- Pending Approval

## APIs

- GET /seller/header
- GET /seller/registration
- POST /seller/registration
- PUT /seller/registration
- POST /seller/registration/submit
- POST /seller/documents
- DELETE /seller/documents/{id}
